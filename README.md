# 🌊 OCF v2.0 – Marine Intelligence OS

## Overview
OCF v2.0 (Oceanic Climate Fishery) is a web-based Marine Intelligence Dashboard designed to visualize real-time oceanographic data and governance protocols. The system presents key marine indicators such as sea surface temperature, wave activity, economic yield projections and species distribution through an interactive and visually rich interface.

This project was developed in the **4th Semester under the Web Development course**.

---

## Features

- **Live Marine Analytics**
  - Sea Surface Temperature (SST) tracking
  - Climate risk level based on wave activity
  - Economic yield projections
  - Species population distribution

- **Real-Time Data Integration**
  - Fetches live marine data using external APIs
  - Auto-updates dashboard at regular intervals

- **Interactive UI**
  - Dynamic charts powered by Chart.js
  - Light/Dark theme toggle
  - Grid layout toggle
  - Animated background effects

- **Ocean Governance Protocols**
  - Displays structured marine policies
  - Includes authority, description and references

---

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Libraries:** Chart.js  
- **API:** Open-Meteo Marine API

## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ay-2006/ocf-marine-intelligence.git
   ```

2. Navigate to the project folder:
   ```bash
   cd ocf-marine-intelligence
   ```

3. Open `index.html` in your browser  
   (or use Live Server in VS Code for best experience)
